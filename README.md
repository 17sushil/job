# jobdev

Full-stack pnpm + Turborepo monorepo starter with Next.js frontend and Node.js backend.

## Structure

- `apps/frontend` — Next.js App Router
- `apps/backend` — Node.js API
- `packages/shared-types` — shared TypeScript types
- `packages/config` — shared config
- `packages/ui` — shared UI package

## Getting started

```bash
pnpm install
pnpm dev
```

Configure environment variables from each `.env.example` file.
